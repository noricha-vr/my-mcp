# VRChat技術・学術系イベント情報スクレイパー

このスクリプトは [VRC技術・学術系イベントHub](https://vrc-ta-hub.com/event/detail/history/) からイベント情報を抽出してCSVファイルに保存するツールです。

## 機能

- Playwrightを使用してウェブページからイベント情報を取得
- 全ページ（ページネーション）のデータを自動的に抽出
- 以下の情報を抽出:
  - 集会名
  - 日付
  - 時間
  - 発表者
  - テーマ
  - イベントURL (詳細ページへのリンク)
- 抽出したデータをCSV形式とTSV形式の両方で保存

## 動作環境

- Python 3.8以上
- Playwright

## インストール方法

```bash
# 必要なライブラリをインストール
pip install -r requirements.txt

# Playwrightのブラウザをインストール
playwright install
```

## 使い方

```bash
# スクリプトを実行
python scraper.py
```

実行すると、カレントディレクトリに以下のファイルが生成されます:
- `vrc_events_YYYYMMDD_HHMMSS.csv` - CSV形式のデータ（コンマ区切り、ダブルクォート囲み）
- `vrc_events_YYYYMMDD_HHMMSS.tsv` - TSV形式のデータ（タブ区切り）

Microsoft Excelなどの表計算ソフトで文字化けする場合は、TSV形式のファイルを開いてみてください。

## 開発メモ

- BOM付きUTF-8で出力することで、Excelなどで開いた際の文字化けを防止しています
- CSV形式では全フィールドをダブルクォートで囲むことで、カンマを含むデータの分割を防止しています
- TSV形式も出力することで、CSV形式で問題が発生した場合の代替手段を提供しています

## 注意事項

- サイトの構造が変更された場合、スクリプトが正常に動作しない可能性があります
- スクレイピングを行う際は、対象ウェブサイトの利用規約に従ってください
- サーバーに負荷をかけないよう、連続実行は避けてください
